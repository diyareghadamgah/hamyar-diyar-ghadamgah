# راه‌اندازی مخزن مستقل در GitHub

1. با حساب `diyareghadamgah` وارد GitHub شوید.
2. صفحه https://github.com/new را باز کنید.
3. نام مخزن را دقیقاً `hamyar-diyar-ghadamgah` بگذارید.
4. مخزن را **Public** انتخاب کنید تا دریافت کد و Artifactها ساده باشد.
5. گزینه افزودن README، فایل `.gitignore` و License را فعال نکنید؛ این بسته هر سه مورد لازم را دارد.
6. روی **Create repository** بزنید.
7. سپس در Termux، ZIP آماده را استخراج و با دستورهای راهنمای تحویل، محتوا را push کنید.

مخزن پیشنهادی: `https://github.com/diyareghadamgah/hamyar-diyar-ghadamgah`
