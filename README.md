# همیار دیار قدمگاه | Hamyar Diyar Ghadamgah

دستیار هوشمند فارسی مبتنی بر PocketPal AI؛ با هدف اجرای مدل‌های زبانی روی دستگاه اندرویدی، نگهداری کد در GitHub و توسعه مرحله‌ای با کمک Termux و GitHub Actions.

> **وضعیت پروژه:** نسخه پایه PocketPal 1.22.0 به‌همراه فارسی‌سازی اولیه و پروفایل پیشنهادی «همیار دیار قدمگاه». این مخزن هنوز نسخه نهایی فارسی، راست‌چین کامل یا APK آزمایش‌شده روی گوشی نیست.

## امکانات آماده‌شده

- فارسی به‌عنوان زبان پیش‌فرض نصب تازه.
- تکمیل چهار کلید ترجمه باقی‌مانده در فایل فارسی.
- اعتبارسنجی ساختار ترجمه‌ها و ثبت فونت‌ها.
- پروفایل و دستورالعمل فارسی برای دستیار «همیار دیار قدمگاه» در `docs/custom-pal/`.
- راهنمای توسعه و مدیریت مخزن از Termux.

## موارد باقی‌مانده

- راست‌چین‌سازی سراسری و آزمون صفحه‌به‌صفحه.
- بازبینی نمایش اعداد، تاریخ و ورودی‌های فارسی.
- تغییر نام، شناسه بسته و هویت بصری اندروید با رعایت امکان نصب مستقل.
- انتخاب مدل GGUF مناسب سخت‌افزار گوشی.
- ساخت و آزمایش APK روی دستگاه واقعی.

## شروع در Termux

```bash
pkg update && pkg upgrade -y
pkg install -y git nodejs-lts yarn python zip unzip

git clone https://github.com/diyareghadamgah/hamyar-diyar-ghadamgah.git
cd hamyar-diyar-ghadamgah
node scripts/validate-l10n.js
node scripts/verify-fonts.js
```

نسخه Node موردنیاز پروژه در حال حاضر حداقل `22.21.0` است. نسخه موجود در مخازن Termux را بررسی کنید. ساخت Native اندروید روی خود گوشی ممکن است با محدودیت حافظه، فضای ذخیره‌سازی و ابزارهای SDK/NDK روبه‌رو شود؛ برای ساخت قابل‌اتکا از GitHub Actions استفاده کنید.

راهنمای کامل‌تر: [`TERMUX-PERSIAN-START.md`](TERMUX-PERSIAN-START.md)

## ساخت APK

از GitHub به مسیر **Actions → Build Android APK → Run workflow** بروید. این workflow در حال حاضر دستی است و خروجی را به‌صورت Artifact در همان اجرای workflow بارگذاری می‌کند؛ APK هنوز Release عمومی یا امضاشده برای انتشار فروشگاهی نیست.
